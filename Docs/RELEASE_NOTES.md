# QuietSpeak 0.1.4

原生 macOS TeamSpeak 3 客户端，支持频道浏览、频道聊天和 Opus 语音。

- 保留三栏布局，使用系统灰色、蓝色操作按钮和更简洁的选中状态。
- 恢复标准 macOS 标题栏，将 Logo 放到服务器侧栏。
- 删除口号、徽章及重复提示，精简成员与聊天样式。
- Dock、侧栏、菜单栏共用自定义图标；菜单栏不再显示默认耳机图标。
- 保留 0.1.3 的频道消息重复显示修复。

要求 macOS 14 或以上。下载与 CPU 对应的 App zip，解压后打开 `QuietSpeak.app`。版本仍为开发预览，使用 ad-hoc 签名，尚未公证。

语音支持 OpusVoice/OpusMusic。全局按键说话、回声消除、私信发送、文件传输及旧编码支持仍未实现。双端通话、蓝牙和更多系统版本仍需手动验证。

源码包包含固定第三方源码。完整变化见 CHANGELOG，校验值见 SHA256SUMS 文件。
