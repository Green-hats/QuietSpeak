# QuietSpeak 0.1.3 — 开源开发预览

原生 macOS TeamSpeak 3 客户端，支持连接服务器、频道与成员浏览、频道聊天、Opus 语音和菜单栏控制。

这一版本修复频道消息发送后重复显示的问题：自己的消息在服务器确认成功后显示一次，不再重复加入服务器回显。连续发送相同文字仍保留为多条独立消息。增加了 6 项聊天回归测试，覆盖确认/回显顺序、发送失败、重连和其他成员消息。

开源许可证、第三方来源、本地补丁、构建测试和双架构 CI/发布流程沿用 0.1.2。新安装默认没有私人服务器收藏；现有收藏和身份保留。

要求 macOS 14 或以上。请选择与 CPU 对应的 App zip，解压后打开 `QuietSpeak.app`。源码包包含构建所需的固定第三方源码。

语音支持 OpusVoice/OpusMusic；当前没有全局按键说话、回声消除、私信发送、文件传输及旧编码支持。自动构建使用 ad-hoc 签名，尚未公证。双端通话、蓝牙和更多系统版本仍需手动验证。

完整变化见 CHANGELOG，校验值见各架构的 SHA256SUMS 文件。
