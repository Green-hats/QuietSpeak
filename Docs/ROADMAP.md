# 开发路线

以下是计划，不代表当前已实现的功能，也没有承诺完成日期。

## 近期

- 在 macOS 14、15 及较新版本完成双端语音、频道密码和聊天验收。
- 完成 Intel 构建与实际设备验证。
- 音频设备选择、设备断开/切换后的自动恢复。
- 扩大网络抖动、丢包、重连和多说话者回归覆盖。
- 国际化界面和英文翻译。

## 后续

- 全局按键说话、语音激活阈值与输入电平。
- 回声消除和噪声处理。
- 私信发送、身份导入/导出及更完整的权限提示。
- Developer ID 签名、公证和规范的发布安装包。

## 另行评估

- 旧版 Speex/CELT 兼容。
- 文件传输、权限管理和完整服务器管理功能。
- 通用二进制和其他平台。
