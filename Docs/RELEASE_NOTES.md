# QuietSpeak 0.1.6

原生 macOS TeamSpeak 3 客户端开发预览。

- 白色为主、绿色点缀，系统侧栏材质与深浅色外观。
- 原生 NavigationSplitView、List和窗口工具栏；服务器栏使用系统侧栏按钮，频道列表使用“显示”菜单或 ⌘⇧2。
- macOS 26+ 底部语音控制采用 Liquid Glass，旧系统回退为 Material；首页保留居中的品牌 Logo。
- 折叠状态持久保存，切换分栏保留未发送消息；修正底部控制条遮挡输入框。

运行需要 macOS 14+。App 为 ad-hoc 签名，尚未公证；没有全局按键说话、回声消除、私信发送、文件传输或权限管理。安装包保留为草稿，公开源码可自行构建。
