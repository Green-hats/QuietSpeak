# QuietSpeak 0.1.5

原生 macOS TeamSpeak 3 客户端，支持频道浏览、频道聊天和 Opus 语音。

- 恢复绿色主题，以不同深浅的背景区分三栏，适配浅色与深色外观。
- 服务器栏与频道栏可独立折叠，记住显示状态；分隔线支持拖动调整宽度。
- 首页 Logo 居中放在聊天内容区，Dock 图标同步为绿色。
- 增大右上角连接与设置图标及点击区域。
- 保留频道聊天重复显示修复。

要求 macOS 14 或以上。使用与 CPU 对应的 App zip。版本仍为开发预览，使用 ad-hoc 签名，尚未公证。

语音支持 OpusVoice/OpusMusic。全局按键说话、回声消除、私信发送、文件传输及旧编码支持仍未实现。双端通话、蓝牙和更多系统版本仍需手动验证。

源码包包含固定第三方源码。完整变化见 CHANGELOG，校验值见 SHA256SUMS 文件。
